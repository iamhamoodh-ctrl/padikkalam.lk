# Padikkalam.lk

Designed by Hamoodh Mohideen. This export contains the website, study tools, four starter PDFs, Android source, and the signed installer. Your copy can run under accounts you own independently of ChatGPT.

## Publish the website from GitHub

1. Extract the whole ZIP on your computer. Create a repository in your own GitHub account. Upload the extracted files, including the hidden folders `.github` and `.openai`, into the repository root. GitHub Desktop can publish the extracted folder and preserve both hidden directories. A private repository works.
2. Create a Cloudflare account, choose a Workers subdomain, enable Workers AI and R2, and create a private R2 bucket called `padikkalam-uploads`. Check the account’s billing and quota settings before enabling products. Create a scoped deploy API token with Workers Scripts Edit, Workers R2 Storage Edit and Workers AI Read for the chosen account. If the deployment reports a missing permission, use the Cloudflare dashboard’s Workers deployment token template. Find the Cloudflare account ID.
3. Create a Supabase project. Copy the project URL and the **publishable** API key from the project settings. Enable email sign-in. Under Authentication → URL Configuration set Site URL to the website origin, for example `https://padikkalam.YOUR-SUBDOMAIN.workers.dev`. Add that origin followed by `/auth/callback**` to Redirect URLs. Students should open email sign-in links in the same browser they used to request them. For public email sign-in, configure your own SMTP sender in Supabase and test delivery to a student address.
4. To enable **Google and Facebook**, create web OAuth applications in your own Google Cloud and Meta developer accounts. Register the callback shown by Supabase (typically `https://YOUR-PROJECT.supabase.co/auth/v1/callback`) with each provider. Enable each provider in Supabase Authentication, and enter its client/app ID and secret there. For public use, complete the provider’s publication requirements and test with a non-owner account.
5. Open your repository → **Settings → Secrets and variables → Actions**. Under **Secrets**, add `CLOUDFLARE_API_TOKEN` and `PADIKKALAM_ADMIN_EMAIL` (the verified mailbox you use to sign in). Under **Variables**, add `CLOUDFLARE_ACCOUNT_ID`, `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY`. Set `PADIKKALAM_PROVIDERS` to `email,google,facebook` after enabling all three providers. The default is `email`. The defaults for `WORKER_NAME` and `R2_BUCKET` are `padikkalam` and `padikkalam-uploads`; set variables with those names to change them.
6. Go to **Actions → Deploy Padikkalam website → Run workflow**. Open the Workers URL from its output and sign in with your owner mailbox. The initial deployment is owner-only. To admit other signed-in students, set the variable `PADIKKALAM_ACCESS` to `members` and run the workflow again. To connect a domain you own, add it under your Worker’s Domains & Routes and update the Supabase URLs in step 3.
7. Visit `/admin` to review notes, approve or revoke verified contributor badges, and publish update notices. Visit `/tutor` to test a question and follow-up. Workers AI runs through the server binding. The application allows 30 model requests per student per UTC day; account quotas also apply. The chat can send a student’s question, recent turns and chosen excerpt to the model. A copied project starts with the four starter PDFs. Private uploads, accounts and calendars on any earlier host live separately.

GitHub stores your code and runs deployment. Cloudflare serves the website and stores uploads. Supabase authenticates students. GitHub Pages alone serves static files and cannot run this backend. You control the independent deployment even if your ChatGPT subscription changes.

## Student features

After signing in, open Account → Your student profile to claim a unique username, choose a display name and optionally add a profile picture, school, A/L batch year and bio. Students discover profiles under Explore → Contributors. They can follow and unfollow, like notes, post questions, reply and save notes. My uploads → My note insights shows activity on each of their own notes.

Upload supports an individual picture, page photos assembled into a PDF, PDF documents, written notes and voice recordings. Open Explore → Past papers for the linked official 2024 English Physics and Chemistry papers with marking schemes. Explore → Model papers includes original short practice sets and downloadable marking guides in four subjects. Owners can add further past and model papers with specific years, subjects and mediums.

## Install the Android app

Open the supplied APK on Android 8.0 or later. If Android asks, allow installation for the app you used to open the APK. Open Settings in Padikkalam to set your own HTTPS website address. The timer, calendar and local reminders work on-device. Library, upload, sign-in, tutor and owner features open your chosen website in the phone’s browser. Export or import an ICS file to transfer time blocks between website and phone. Enable notifications for time-block alerts. Android can delay alerts if exact alarm access is unavailable.

The supplied AAB is the signed upload for a Google Play Console release. Upload it to a testing track first. Set up your Play developer account, complete the store listing and required disclosures, and test on the phones you intend to support. The AAB and APK both use application ID `lk.padikkalam.study`, version 1.0.0, version code 1. When Play App Signing uses a different app signing key from the direct APK, switch distribution channels by reinstalling; export local time blocks first.

## Rebuild future APKs and AABs

Keep the separate private signing kit backed up. It contains the signing keystore and password. Never commit that kit to a repository. Set GitHub Actions repository secrets `ANDROID_KEYSTORE_BASE64` (contents of android-release.p12 encoded as Base64) and `ANDROID_KEYSTORE_PASSWORD` (one line from password.txt). On Windows, to copy the encoded key privately via PowerShell, use `[Convert]::ToBase64String([IO.File]::ReadAllBytes((Resolve-Path '.\android-release.p12').Path)) | Set-Clipboard`. After pasting the secret, clear the clipboard. The key alias is `padikkalam`. Increase versionCode and versionName in android/app/build.gradle, then run **Actions → Build signed Android releases**. Download the release artifact from the completed run. Play requires an increasing version code for every update.
